# Dev-Shamim-3D-Portfolio

Portfolio of Billal Hosen Shamim, built with React, TypeScript, Tailwind CSS and Framer Motion.

```bash
npm install
npm run dev      # local dev server
npm run build    # type-check + production build to dist/
```

Sections: Hero → Marquee → About → Skills → Projects → Experience → Education → Contact.
All personal content (bio, skills, experience, education, projects, links) lives in `src/data/portfolio.ts`, so edit that file to update the site.
Reusable components live in `src/components` (`FadeIn`, `Magnet`, `AnimatedText`, `ContactButton`, `LiveProjectButton`).

The `influencer-gear/` folder keeps the images, logos and stylesheet from the older Influencer-Gear site.
